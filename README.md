# EmilyTsum Homebrew Tap

Public Homebrew casks maintained by EmilyTsum.

## PlayCover PTMC

PlayCover nightly fork bundled with the PlayTools pre-compositor Metal capture path:

```sh
brew install --cask EmilyTsum/tap/playcover-ptmc
```

Using the fully qualified cask name lets current Homebrew releases trust only this cask rather than the entire third-party tap.

Configure recording per game in **App Settings → Metal Capture**.
